# server (Dia 4)

Aqui vai entrar a API em Node + Express + SQLite.

Rotas planejadas:

| Método | Rota                    | O que faz              |
| ------ | ----------------------- | ---------------------- |
| GET    | /api/characters         | lista todos            |
| GET    | /api/characters/:id     | busca um               |
| POST   | /api/characters         | cria                   |
| PUT    | /api/characters/:id     | atualiza               |
| DELETE | /api/characters/:id     | remove                 |
